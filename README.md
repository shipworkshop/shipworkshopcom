# ARTFORGE — сайт-визитка аутсорс-студии игрового арта

Статический одностраничник без сборки: открывается двойным кликом по `index.html`.

## Структура
- `index.html` — разметка всех секций
- `styles.css` — тема, сетка, адаптив (брейкпоинты 960 / 640 px)
- `main.js` — липкая шапка, мобильное меню, фильтр портфолио, анимация появления, форма
- `assets/` — сюда положите реальные изображения работ

## Что заменить под себя
1. Название и контакты: `ARTFORGE`, `hello@artforge.studio`, `@artforge_studio` — поиск по этим строкам.
2. Портфолио: массив `WORKS` в `main.js` — сейчас это градиентные плейсхолдеры. Замените карточки на `<img src="assets/…">`.
3. Цены в секции «Форматы сотрудничества» и цифры в блоке статистики.
4. Логотипы клиентов в секции `.strip`.

## Форма
Бэкенда нет: форма валидирует поля и открывает почтовый клиент через `mailto:`.
Для реальной отправки подключите Formspree / Getform / свой эндпоинт в обработчике `submit` в `main.js`.

## Публикация
Любой статический хостинг: GitHub Pages, Netlify, Vercel, Cloudflare Pages — залить папку как есть.
